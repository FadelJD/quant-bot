# 02a · Data layer

Created 2026-11-11 · Wave 2 · Parallel with 02b to 02g · Needs 01 · Spec section 6

## Goal

`(market, symbol, timeframe, start, end)` in, a clean cached frame out, and never a silent gap.
Incremental, reproducible, polite to free tiers, and honest when a provider blocks the region.

## Owns

`src/kestrel/data/`, `scripts/fetch_fixtures.py`, `scripts/make_fixtures.py`,
`src/kestrel/_templates/universes/` (content only).

## Current state

Schema validation, parquet cache, manifest, token bucket, synthetic generator, calendars and five
sources exist and run for the synthetic source. Never run against a real provider. Defects D20, D23.

## Work items

1. **Cache writes (D23).** Append the fetched tail and rewrite only the affected partition. Keep
   one file per series until it passes `max_partition_mb`, then one file per year. Write to a temp
   file and `os.replace` so a crash never leaves a half-written parquet (works on Windows too).
   Fix `empty_ohlcv` to drop the unused arguments.
2. **Incremental fetch.** Cover three cases explicitly: empty cache, missing head, missing tail.
   A second identical request must make zero source calls. Expose `DataService.fetch_calls` and
   per-source `calls` counters (already present) so wave 5 can assert it.
3. **Gap policy.**
   - Crypto: any step larger than one bar is a gap.
   - Equities (D20): build the expected index from `NyseCalendar.sessions()` and diff against it;
     drop the weekend heuristic.
   - `allow_gaps: true` forward-fills, sets a boolean column `filled`, and logs one line per gap.
     Strategies never see `filled`; the report's data manifest lists the count.
4. **Manifest.** One entry per series: source, fetch time, rows, first and last timestamp, file
   path, **content hash** (SHA-256 of the parquet bytes). Add `Manifest.fingerprint()` so run
   provenance (02g) can record exactly which data a run used.
5. **Rate limiting.** One `TokenBucket` per source instance. Backoff on 429 with jitter capped at
   60 s. Honour a `Retry-After` header when the exception carries one. CCXT keeps
   `enableRateLimit=True` as well.
6. **Region errors.** Route every source through `errors.raise_if_region_blocked(exc, provider)`
   (provided by plan 01, shared with 02e). HTTP 451, 403 with a location message, and Binance's
   "restricted location" text all become `AdapterError("provider X blocked from this region")`.
7. **Sources, verified against current docs.** For each, read the provider's docs and record the
   URL and date in the handoff note (04c writes them into `docs/thailand.md`):
   - CCXT public OHLCV: pagination limits per exchange (Binance 1 000, Bybit 1 000, OKX 100 to 300),
     default exchange choice, depth of 1h and 1d history.
   - Alpaca free tier: IEX feed limits, how far back daily bars go, the 15-minute rule for recent
     data, request rate.
   - `yfinance`: research only; print a warning; refuse to serve a live run (`DataService` takes a
     `purpose` argument, `research` or `live`).
8. **Calendar.** Daily equities bars: store `ts` as the session date at 00:00 UTC, document it,
   and make `next_bar_close` return the real session close including early closes. Crypto bars
   align to UTC boundaries. Remove the `lru_cache` on a method (B019) with a plain dict.
9. **Universes.** Dated YAML with `market`, `as_of`, `symbols`, `note`. Keep `crypto_top20`,
   `us_large_cap_30`, `synthetic_5`. Add a loader check that every symbol matches the market's
   format (`BASE/QUOTE` or a ticker).
10. **Fixtures.**
    - `make_fixtures.py`: deterministic synthetic set, 5 crypto pairs and 10 stocks, 2 years daily,
      float32, under 2 MB total, plus a frozen `market_meta.json` with lot step, tick size and
      minimum notional per symbol (the backtester reads it).
    - `fetch_fixtures.py`: the real-data version for the owner's machine; same output layout.
    - Commit the synthetic set now. Record in the handoff note that real fixtures need the owner.
11. **I10 cross-source check.** `DataService.cross_check(symbol, timeframe, start, end, other)`
    returns the fraction of bars whose closes differ by more than a tolerance (default 0.5%) and
    the worst date. Exposed later by `kestrel data check --against kraken`. Read-only, public data.
12. **Resampling helper.** `resample_ohlcv(frame, to)` for 1h to 4h or 1d, so one cached series can
    serve several timeframes. Pure function.

## Done when

- Synthetic and fixture sources serve the full quickstart with zero network calls.
- Cache files survive a simulated crash between write and rename.
- `kestrel data fetch` twice in a row prints the same rows and the second run reports zero fetches.
- The four static checks pass on `src/kestrel/data/`. Smoke gate green.
- D20, D23 closed. Provider facts recorded with URL and date.

## Out of scope

Execution-side data (quotes, orders). Point-in-time universes (v2). Tests.
